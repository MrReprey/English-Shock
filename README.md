Bienvenidos al proyecto de Aprendizaje de Ingles "DIROC" este sistema esta desarrollado en Laravel, React y la base de datos los manejamos con MySQL 

El proposito de este proyecto es tener un controlador de versiones para este juego educativo demostrando las propiedades y ventajas de git y muchas de sus funciones que nos permiten almacenar nuestro codigo en repositorios
a los cuales tendremos acceso ya sea de forma local o global


En cuanto al proyecto es un juego educativo el cual consta de dos modalidades una que es modo Solitario y el modo Multijugador en donde un grupo de personas compiten por ver quien es mas rápido pensando en ingles
